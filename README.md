# voice-os-agent

Голосовой агент для управления операционной системой Windows командами и голосом.

## Структура

```
agent/
├── config/
│   └── config.json              # настройки: wake word, TTS, политика безопасности
├── src/voice_os_agent/
│   ├── __main__.py              # python -m voice_os_agent
│   ├── app.py                   # сборка и запуск агента (голос / текст)
│   ├── core/
│   │   ├── agent.py             # главный цикл: разбор -> проверка -> исполнение
│   │   └── settings.py          # загрузка конфигурации
│   ├── nlu/
│   │   ├── intents.py           # IntentType и структура Intent
│   │   ├── patterns.py          # шаблоны команд (RU/EN)
│   │   └── parser.py            # парсер текста в Intent
│   ├── executors/
│   │   ├── base.py              # BaseExecutor, ExecutorRegistry, ExecutionResult
│   │   ├── apps.py              # запуск/закрытие приложений
│   │   ├── system.py            # громкость, питание, блокировка
│   │   ├── shell.py             # выполнение разрешённых команд
│   │   ├── window.py            # скриншот, окна, рабочий стол
│   │   └── files.py             # открытие папок и путей
│   ├── voice/
│   │   ├── asr.py               # распознавание речи (SpeechRecognition)
│   │   ├── tts.py               # синтез речи (pyttsx3)
│   │   ├── microphone.py        # источник звука на sounddevice (без PyAudio)
│   │   └── wake_word.py         # детектор слова-триггера
│   ├── security/
│   │   └── guard.py             # подтверждение опасных действий и whitelist
│   ├── cli/
│   │   └── console.py           # текстовый режим для отладки
│   └── utils/
│       └── win32.py             # WinAPI: хоткеи, скриншот
└── tests/                       # pytest
```

## Как это работает

1. `voice/` слушает микрофон и ждёт слово-триггер (`ассистент` по умолчанию).
2. `nlu/` превращает фразу в `Intent` (намерение + сущности).
3. `security/` проверяет намерение: опасные действия требуют подтверждения, shell-команды ограничены whitelist.
4. `executors/` выполняют действие и возвращают результат.
5. Ответ озвучивается через `tts/`.

## Установка

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```

Ключевые зависимости:
- `pyttsx3` — синтез речи;
- `SpeechRecognition` — распознавание речи;
- `sounddevice` + `numpy` — захват микрофона (не требует компилятора);
- `pycaw` + `comtypes` — управление громкостью.

Конфигурация — обычный JSON (без внешних зависимостей).

`PyAudio` ставится опционально (`pip install -e ".[audio]"`) и используется, если он есть; иначе
микрофон захватывается через `sounddevice`. `pip install -e . --no-deps` оставляет рабочим только
текстовый режим.

На Python 3.15 библиотека `comtypes` печатает `FutureWarning` при первом обращении к громкости —
это её собственное предупреждение, на работу агента оно не влияет.

## Запуск

Текстовый режим (без микрофона):

```
python -m voice_os_agent --text
```

Голосовой режим:

```
python -m voice_os_agent
```

То же самое после установки пакета — команда `voice-agent` (скрипт попадает в `Scripts` каталога
Python; если его нет в `PATH`, вызывайте `python -m voice_os_agent`).

Опции: `--config PATH`, `--no-tts`.

## Примеры команд

| Фраза | Действие |
| --- | --- |
| открой браузер / открой блокнот | запуск приложения |
| открой / запусти приложение | запуск приложения (синонимы) |
| закрой хром / заверши chrome | закрытие приложения |
| открой папку загрузки | открыть путь в проводнике |
| открой рабочий стол / мои документы | системные папки |
| поставь громкость 40 | установить громкость |
| увеличь громкость на 10 | изменить громкость |
| выключи звук | mute |
| выключи компьютер | завершение работы (с подтверждением) |
| заверши работу / выключи работу | завершение работы (с подтверждением) |
| перезагрузи компьютер | перезагрузка (с подтверждением) |
| спящий режим / заблокируй компьютер | питание / блокировка |
| отмена | отмена запланированного питания |
| сделай скриншот | снимок экрана |
| сверни все окна / покажи рабочий стол | управление окнами |
| выполни ipconfig | shell-команда из whitelist |
| запусти команду ipconfig | shell-команда из whitelist |

Команды подтверждаются словами `да`/`нет`; опасные действия (выключение, перезагрузка, сон)
требуют подтверждения, а shell-команды ограничены whitelist: цепочка вроде
`выполни ipconfig & format c:` отклоняется целиком.

## Расширение

- Новое действие: добавить `IntentType`, шаблон в `nlu/patterns.py` и исполнитель в `executors/`.
- Новое приложение: дополнить словари `KNOWN_APPS` и `PROCESS_NAMES` в `executors/apps.py`.
- Разрешить shell-команду: добавить её в `security.shell_whitelist` в `config/config.json`.
- Подключить LLM-разбор: заменить `IntentParser` на собственную реализацию с тем же интерфейсом.
